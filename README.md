OverviewThe Arris E6000 Command Center (CMTS_Command_Center.py) eliminates slow manual SSH hops, repetitive CLI typing, and manual spreadsheet parsing when troubleshooting Arris E6000 Converged Edge Routers (CER).Engineered with a non-blocking Paramiko SSH jump-host state machine, a live Matplotlib 2x2 RF/Speed telemetry canvas, an automated root-cause heuristics engine, and a local SQLite Flight Recorder, it transforms raw CMTS text output into actionable visual intelligence in seconds.Application Visual Overview1. Split-Screen RF Spectrum & Speed Visualizer (Obsidian Tactical Theme)When executing RF, SNR, Service Flow, or Jitter commands, the console automatically docks a 2x2 Analytics Grid right alongside your live syntax-highlighted terminal output:


Key Architecture and FeaturesBastion Jump-Host Proxy & Single-Password VIP Handshake: Automatically authenticates through your corporate SSH Jump Host (Bastion Password = Base_Password + 6-Digit VIP Token) and seamlessly hops into the target Arris E6000 CMTS (CMTS Password = Base_Password), automatically setting page-length 0.Thread-Safe Keep-Alive Heartbeat: Background daemon sends a silent heartbeat every 45 seconds so neither the Bastion gateway nor the E6000 chassis drops your idle terminal session.2x2 Real-Time Speed, Jitter & RF Visualizer: Parses CLI text on the fly to render four explicit, labeled Matplotlib charts:Upstream SNR Carrier Spectrum (dB): Color-coded bars (Green: 28 dB or higher, Amber: 25 to 27.9 dB, Red: below 25 dB) with a 28.0 dB threshold floor line.Modem Bufferbloat & Jitter Matrix (ms): Tracks Average Jitter, Peak Delay, and Buffer Underflow/Overflow drops.Throughput & Capacity Saturation (Mbps): Compares active Downstream/Upstream rates against QoS provisioned caps.Live Telemetry & Signal History: Rolling time-series plot tracking SNR (dB) and Jitter (ms) across continuous polling intervals.Automated Root-Cause Heuristics Engine: Evaluates command output against DOCSIS engineering thresholds (Upstream SNR below 28 dB, Tx Power at or above 53.0 dBmV, Jitter above 25 ms, Uncorrectable Codeword spikes) and generates a plain-English root-cause triage report.Double-Click MAC Drilldown: Double-clicking any MAC address (001a.2b3c.4d5e or 00:1a:2b:3c:4d:5e) in the terminal output automatically populates the Query Parameters, switches the workflow to Individual Modem Diagnostic, and stages the CLI prompt.Built-In Terminal Search (Ctrl+F) & 1-Click Copy: Search thousands of lines of CLI output with instant match highlighting and jump buttons, or copy the entire terminal buffer to your clipboard in one click.Pre/Post Maintenance Snapshot & Unified Diff Engine: Capture a 1-click baseline (show cable modem summary port mac + show cable flap-list) prior to a maintenance window or fiber cut repair, and run a unified post-maintenance comparison afterwards.Local SQLite Flight Recorder: Every command and full CLI response is automatically indexed in flight_recorder.db by timestamp and hostname for instant offline search and historical replay.4 Dynamic Runtime Themes: Switch seamlessly between Obsidian Tactical, Retro CRT Amber, Phosphor Matrix, and Cyberpunk 2077 with zero restart required.Unrestricted Plain-Text CLI Dock: Send any ad-hoc diagnostic, pipe (|), or configuration command directly to the active SSH channel with zero control-character artifacts.Installation and Standalone CompilationPrerequisitesEnsure you have Python 3.10+ installed on Windows, macOS, or Linux.Clone or download the repository:git clone https://github.com/your-org/arris-e6000-command-center.git
cd arris-e6000-command-center
Install required dependencies:pip install customtkinter paramiko matplotlib openpyxl pillow pyinstaller
Launch the application directly via Python:python CMTS_Command_Center.py
Compiling a Standalone Windows Executable (.exe)You can package the entire suite into a single-file, zero-dependency Windows executable with the custom icon:# 1. Generate the multi-resolution arris_e6000.ico badge (if using generate_icon.py)
python generate_icon.py

# 2. Clean previous build artifacts and compile into a single standalone executable
Remove-Item -Recurse -Force .\build, .\dist -ErrorAction SilentlyContinue
python -m PyInstaller --noconsole --onefile --icon=arris_e6000.ico --add-data "arris_e6000.ico;." --collect-all customtkinter --collect-all matplotlib --clean CMTS_Command_Center.py
Your standalone executable will be generated at dist\CMTS_Command_Center.exe.Step-by-Step Operator TutorialStep 1: Configure Target and AuthenticationIn the left sidebar under Dispatch Target and Bastion & Credentials, enter:Target CMTS Hostname: The hostname of the Arris E6000 chassis (e.g., cncnohjy05m).Bastion Jump Host: Your corporate SSH gateway IP or FQDN (saved automatically to config.json on exit).Operator P-Number: Your network operator ID (e.g., P1234567).User / Enable Password: Your standard corporate password.When you trigger your first command, a pop-up dialog will ask for your 6-digit VIP Token.How it works: The app automatically concatenates Password + VIP_Token for the Bastion login, then uses your Password alone to authenticate into the E6000 CMTS. Once connected, the top-left status indicator turns green (CONNECTED: CNCNOHJY05M), the credentials drawer auto-collapses, and the session remains locked open.Step 2: Running Single-Node Diagnostic WorkflowsEnsure the dispatch mode toggle at the top of the sidebar is set to Single Node.Open the Diagnostic Workflow dropdown and choose from the pre-engineered workflows (such as Modem Counts (Port Summary), Cable Noise & SNR Summary, or Individual Modem Diagnostic).Fill in any visible Query Parameters (e.g., Cable-Mac ID: 12 or Drilldown Modem MAC). Unused parameter boxes automatically hide themselves to prevent input errors.Click Execute Workflow.Reviewing the Results:Top KPI Bar: Automatically updates ONLINE RATIO, TOTAL MODEMS, OFFLINE COUNT, RF CODEWORDS, and TRIAGE STATUS.Split View: If the command returns RF, SNR, or codeword metrics, the 2x2 Matplotlib Visualizer automatically opens alongside the terminal.Heuristics Tab: Click Heuristics in the top navigation bar to read the automated root-cause analysis report.Step 3: Interactive Double-Click MAC DrilldownWhen viewing a large table such as show cable flap-list, show cable modem rogue, or show cable modem heavyhitter:Locate any suspect modem in the terminal window (problematic lines are automatically highlighted in Red for offline/drops or Amber for ranging/flapping).Double-click directly on the MAC address in the terminal text.The app will automatically:Extract the MAC address and insert it into the Drilldown Modem MAC input box.Switch the active workflow to Individual Modem Diagnostic.Pre-fill the bottom CLI dock with show cable modem <MAC> verbose.Click Execute Workflow (or press Enter in the CLI dock) to immediately inspect the modem.Step 4: Using Live Watch (Continuous Polling Mode)When actively troubleshooting intermittent noise ingress or watching modems recover after a reset:Select your desired workflow (e.g., Cable Noise & SNR Summary on cmac 1).In the Live Watch Polling box in the sidebar, select your polling interval (Every 3s, Every 5s, Every 15s, or Every 30s).Click Start Watch.The terminal and the Split View charts will update continuously on every cycle until you click Stop Watch.Step 5: Pre/Post Maintenance Window Validation (Unified Diff)Before performing plant maintenance, node splits, or optics swaps:Enter the target CMTS hostname and click Snapshot (Pre).The app captures show cable modem summary port mac | include mac and show cable flap-list and stores the baseline in memory.Perform your maintenance activity.Click Compare (Post).The app re-polls the chassis, switches to the Maint Diff view, and displays a line-by-line unified diff (+ / -) showing any ports that lost registered modems or new MACs that began flapping.Step 6: Bulk Fleet Auditing and Multi-Tab Excel ExportTo run a health check across multiple CMTS chassis at once:Switch the mode toggle at the top of the sidebar to Bulk Fleet Audit.In the Target Fleet textbox, paste a comma-separated or newline-separated list of CMTS hostnames:cncnohjy01m, cncnohjy02m, cncnohjy05m, cncnohjy08m
Choose a chassis-wide workflow (e.g., Modem Counts (Port Summary) or Upstream Capacity Summary) and click Run Fleet Audit.Once complete, click Export Excel in the top header bar.The app generates a formatted .xlsx workbook where each CMTS node is placed on its own dedicated worksheet tab with navy headers, alternating zebra rows, and auto-fitted column widths.Step 7: Offline Replay with the Flight RecorderEvery command you execute is permanently saved to your local flight_recorder.db SQLite database.Click History in the top navigation bar.Type a CMTS hostname, MAC address, or keyword into the search bar and press Enter (or click Search History).Click any historical log entry on the left list to replay the exact CLI output on the right pane—even when completely offline.Built-In
